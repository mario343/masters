# Analiza cech — materiały archiwalne

Notebooki w tym katalogu dokumentują wcześniejszą analizę zależności między
cechami, redukcję wymiarowości i symbolic regression. Nie są automatycznie
uruchamiane przez skrypty głównego pipeline'u.

Kopie notebooków są w `correlation/notebooks/`, a wygenerowane wykresy i pliki
wynikowe w `correlation/results/`.
